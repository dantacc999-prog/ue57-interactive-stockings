# 最终制作流程

## 1. 准备身体与袜子

使用完整的连裤袜 Skeletal Mesh，保留原 UV、袜口、裆部与脚部拓扑。袜子和身体必须在同一参考空间，长度以 UE 厘米计。先确认原动画下身体、泳装与鞋子的贴合，再接入变形。

对读取 LOD0 数据的身体和袜子启用 CPU Access。袜子采用身体的 Leader Pose；互动期间下肢使用临时后处理站姿，上身仍保留进入互动时的姿态。骨骼匹配点为 `Hips`、`UpperLeg_L/R`、`LowerLeg_L/R`、`Foot_L/R`。

## 2. 建立程序网格

`StockingsGeometry.cpp` 从 LOD0 读取参考位置、当前蒙皮位置、UV 和三角索引。每个原三角面做一次细分，得到足够的轴向采样；UV 顶点不合并，另按参考位置建立接缝组。

渲染保留 UV 接缝；位置修正和纤维密度以接缝组为单位同步。原顶点的焊接拓扑用于袜口抓取的邻接搜索。创建和更新程序网格时都显式关闭顶点色 sRGB 转换，让 `R*2.4` 始终代表同一纤维密度。

## 3. 建立身体与内层服装接触

读取实际站姿的身体材质槽三角面，构建 BVH。最近点、插值伪法线和局部有符号距离用于贴合；这里的距离是最近特征局部判定，不是全局封闭体内外分类。

内层服装按材质槽和参考空间包围范围筛选。示例中的泳裤、四个扣环和左右两组侧带全部纳入，九个独立部件共 1204 面。接触方向跟随底下身体的外侧，闭合扣环的背面不会把外层袜面推向身体。

点投影后，再用三角面分离轴检测实际交叉，按接缝组修正。身体默认渲染间隙 .18 cm，泳装局部间隙 .14 cm；不要用扩大整条袜子的方法代替局部层间处理。

## 4. 抓取与响应

青色点代表左右袜口。射线选择袜口后，鼠标移动投影到面向相机的平面，转换成袜子组件局部位移。拓扑上的距离权重形成单侧局部拉伸区，避免直接抓住另一条腿。

向外拉动时，目标局部偏移为拖动量的 .6 倍，最大 5 cm；松手后按 `1-exp(-22*dt)` 快速收紧。

向下位移超过 .5 cm 且大于横向位移的 1.3 倍时，进入下拉模式。默认袜口前沿以 32 cm/s 向目标移动。松手将目标高度固定为当前高度，不回到腰部。

## 5. 将整件袜子收拢到脚踝

`StockingsVisualAtlas.cpp` 从实际身体轮廓生成高度截面：128 个高度采样、每个截面 64 个方向。左右腿与躯干截面平滑混合，袜子沿对应轮廓移动。

高度映射保持单调，并在收拢前沿平滑过渡。脚踝附近保留有限宽度的堆叠带，避免所有顶点挤到同一平面。折叠偏移受压缩程度控制，默认振幅 .12 cm，最大 .15 cm。只平滑位移场，不反复抹平原始模型表面。

停止位置来自脚骨参考高度和服装高度；示例最大下拉约 62.9 cm。成品范围到脚踝，仍保留脚掌上的袜面。

## 6. 纤维密度与材质

按每个接缝组的参考面积/当前面积得到密度，限制在 .62..2.4，并沿邻接做少量平滑。顶点色 R 编码 `density/2.4`。拉伸区域更薄，压缩区域更厚；脚踝堆叠会自然更不透明。

纱网材质的经纬纹理锚定到 UV。解析纤维截面、交错覆盖、孔隙和高光共同构成织物；`fwidth` 让远处纹理收敛到平均覆盖率，减少闪烁。透明孔隙不复制皮肤颜色，皮肤来自独立身体网格。

白色使用独立光学密度范围、暖肤色和柔和纤维光泽；黑色使用冷黑色纤维。身体覆盖区域的柔和着色和袜面光域协调，袜口以上仍保留原皮肤着色。

## 7. 普通状态、鞋子与镜头

普通状态直接渲染原 Skeletal Mesh，不运行下拉变形；黑白普通材质与互动材质使用相同组件灯光锚点。白色普通材质还从参考/当前表面导数估算面积密度。

`ShoesWorn` 同时控制袜面低趾尖遮罩和身体鞋内遮罩，脱鞋后恢复。中键旋转、右键平移、滚轮缩放由共享相机库处理，互动时也可观察背面和近距离细节。

## 8. 接入与验收

按 [integration.md](integration.md) 设置宿主 Widget、材质、骨骼与槽位；按 [materials.md](materials.md) 接入自己角色的皮肤和 UV 覆盖。检查白/黑/无袜切换、普通与互动、外拉释放、下拉保持、脚踝收拢、鞋开关和不同观察角度。

使用 `GetAcceptedValidationMesh()` 导出实际渲染网格，通过 `Tools/validate_mesh.py` 检查接缝与泳装交叉。截图只展示视觉效果，几何交叉需要单独检查。
