## 导出自己的网格

运行时调用 `GetAcceptedValidationMesh()` 获取 JSON，字段包括渲染位置/三角索引、接缝组、模拟和渲染纤维密度、身体和内层服装的实际面。另用 `GetSimulationStats()` 确认 `fit_ready`、当前进度与脚踝高度。

```python
# UE Editor Python，InteractionActor 为运行中的 Actor 对象
from pathlib import Path
Path("C:/Temp/stockings_mesh.json").write_text(
    InteractionActor.get_accepted_validation_mesh(), encoding="utf-8")
```

在普通 Python 中：

```bash
python -m pip install -r Tools/requirements.txt
python Tools/validate_mesh.py C:/Temp/stockings_mesh.json
```

检查器输出泳装三角交叉数、最大接缝误差和实际顶点色密度量化误差。它验证导出的当前帧，不是连续时间碰撞证明。

## 当前限制

互动仅站姿；普通状态可保留原动画。下拉到脚踝，仍保留脚掌袜面。收拢轮廓与纱网细节质量受原模型分辨率和 UV 影响；不是任意角色通用的全耦合布料模拟。当前仅单用户本地交互，未实现网络同步或多人抢抓。
